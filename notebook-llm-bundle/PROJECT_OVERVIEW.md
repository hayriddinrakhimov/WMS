# WMS «Атамекен-Агро» — обзор проекта

## Назначение

Демонстрационная система управления складом (WMS) для агрохимического холдинга **Атамекен-Агро**. Покрывает полный цикл: от заявки на закуп и импорта маркировки Упак до приёмки, хранения, выдачи агрономам и утилизации пустой тары.

## Платформы

| Платформа | Описание |
|-----------|----------|
| **Веб-кабинет** | Next.js 16, десктопный интерфейс с боковым меню, вкладками модулей, дашбордом |
| **ТСД (мобильный)** | Адаптивный UI в стиле терминала сбора данных — сканирование, задачи, операции |

## Вход

Аутентификация по **OTP-коду** (демо-пользователи в `lib/auth.ts`). Без паролей — быстрый переключатель ролей для презентации.

## Ключевые возможности

- **Снабжение:** спрос, заявки на закуп (ЗН-xxx), сводные, заказы поставщику, импорт Упак.
- **Склады:** остатки, ячейки, ожидаемые приёмки (ОП-xxx), складские операции и задания (ОТБ-xxx).
- **Сканирование:** иерархия палета → коробка → канистра (SSCC / SGTIN).
- **Отчёты:** остатки, движения, история канистры (PDF).
- **Главная:** executive dashboard с KPI, задачами, виджетами по ролям.

## Предприятия

Головное **Атамекен-Агро**, дочерние **ТОО 1**, **ТОО 2**, филиалы Астана и Шымкент.

## Стек (для справки, не для слайдов)

Next.js 16, React 19, TypeScript, Tailwind CSS 4, Lucide Icons. Монорепо: `packages/domain` (бизнес-логика), `packages/modules` (экраны модулей).

## Запуск

```bash
npm install
npm run dev
```

Открыть в браузере, ввести OTP (666, 111, 222 или 333).
