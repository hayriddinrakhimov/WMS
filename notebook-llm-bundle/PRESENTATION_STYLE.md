# Дизайн-система для слайдов презентации WMS

Источник: `app/globals.css`, компоненты `WebSidebar`, дашборд (`dash-*`), ТСД (`tsd-*`), модульные панели.

---

## 1. Цветовая палитра

### Основные

| Токен | HEX | Применение на слайдах |
|-------|-----|----------------------|
| `--foreground` | `#212121` | Заголовки, основной текст |
| `--muted-foreground` | `#757575` | Вторичный текст, подписи |
| `--app-muted` | `#6B7280` | Метки, uppercase-лейблы |
| `--app-page` | `#F0F2F5` | Фон слайда (светло-серый) |
| `--app-surface` | `#FFFFFF` | Карточки, панели контента |
| `--app-border` | `#E0E4EA` | Рамки, разделители |

### Акцент (бренд)

| Токен | HEX | Применение |
|-------|-----|------------|
| `--primary` / `--app-accent` | `#2A48FF` | CTA, активные шаги, ссылки, иконки в сайдбаре |
| `--primary-hover` | `#2340E6` | Hover-состояния (если интерактив) |
| `--primary-soft` / `--app-accent-soft` | `#E9EEFF` | Фон акцентных бейджей, подсветка активного шага |

### Семантика дашборда

| Токен | HEX | Фон (soft) | Смысл |
|-------|-----|------------|-------|
| `--dash-green` | `#0D7A52` | `#E6F5EF` | Успех, выполнено, приёмка |
| `--dash-amber` | `#B45309` | `#FEF3C7` | Предупреждение, ожидание |
| `--dash-red` | `#C62828` | `#FDECEA` | Ошибка, утиль, списание |
| `--dash-slate` | `#475569` | `#F1F5F9` | Нейтральный статус, черновик |

### Дополнительные (операции ТСД)

- Фиолетовый `#7C3AED` / фон `#F3E8FF` — перемещение, трансфер.
- Индиго — активные задания в процессе.
- Розовый — возврат тары.

## 2. Типографика

**Шрифт:** `'Segoe UI', system-ui, -apple-system, Roboto, sans-serif`  
(задан в `@theme inline --font-sans`)

| Уровень | Размер / стиль | CSS-референс |
|---------|----------------|--------------|
| Hero-заголовок | 28–32 px, bold, tracking-tight | `.dash-exec-hero__title` |
| Заголовок слайда | 22–24 px, bold | `.dash-hero__title`, `.module-landing__title` |
| Подзаголовок | 14–15 px, regular, muted | `.dash-hero__subtitle` |
| Основной текст | 14 px | body, `.module-content-table` |
| Метка секции | 11 px, semibold, uppercase, letter-spacing wider | `.dash-section-title`, `.dash-today__heading` |
| KPI-число | 24–32 px, bold, tabular-nums | `.dash-kpi__value` |
| Моноширинный код | font-mono, 13–14 px | SSCC, SGTIN в ТСД (`.tsd-scan-hit__code`) |

**Antialiased** — сглаживание текста включено глобально.

## 3. Компоновка и сетка

- **Максимальная ширина контента:** 1440 px (`.dash-exec__inner max-w-[1440px]`).
- **Отступы:** 16–24 px на мобильном, 24 px на десктопе (`p-4 md:p-6`).
- **Карточки:** `rounded-2xl` (16 px), border `1px #E0E4EA`, тень `0 1px 2px rgba(15,23,42,0.04)`.
- **Внутренние панели:** `rounded-xl` (12 px), фон `#F8FAFC` для вложенных блоков.
- **Сайдбар (референс):** ширина 248 px, белый фон, логотип «Атамекен-Агро», аватар AA на `#2A48FF`.

### Сетки

- KPI: 2–5 колонок (`.dash-kpi-strip`).
- Двухколоночный layout: основной + боковая панель 22 rem (`.dash-exec-layout`).
- Карточки модулей: 2–3 колонки (`.module-landing__grid`).

## 4. Типы слайдов

### A. Титульный / Hero

- Фон: градиент `#FFFFFF → #F8FAFF → #F4F7FF` (как `.dash-exec-hero`).
- Белая карточка с лёгкой тенью `0 1px 3px rgba(15,23,42,0.05)`.
- Логотип-круг AA на `#2A48FF`, название «Атамекен-Агро».

### B. KPI / метрики

- Ряд из 3–5 карточек с цветной полоской сверху (`.dash-kpi--blue/green/amber/red`).
- Число крупно, подпись 12 px muted.

### C. Процесс / пайплайн

- Горизонтальная цепочка кругов (`.dash-pipeline`):
  - **done:** заливка `#2A48FF`, белый текст.
  - **active:** border `#2A48FF`, фон `#E9EEFF`, glow `0 0 0 4px #E9EEFF`.
  - **pending:** border `#E0E4EA`, белый фон, muted текст.
- Соединители: линия 2 px, done — `#2A48FF`, pending — `#E0E4EA`.

### D. Таблица / реестр

- Заголовки: 12 px, muted, border-bottom.
- Строки: hover `#FAFBFC`, padding 12–16 px.
- Номера заданий — цвет `#2A48FF` (`.dash-task-table__num`).

### E. Мобильный ТСД

- Узкий фрейм (~320 px), фон `#F0F2F5`.
- Кнопки: `rounded-xl`, primary `#2A48FF`, full-width.
- Карточки задач: `rounded-2xl`, тень лёгкая.
- Scan-hit канистры: зелёная рамка `#0D7A52` / фон `#E6F5EF`.

### F. Статусы (бейджи)

- Pill: `rounded-full`, padding 4–10 px, 11–12 px font semibold.
- Цветовая пара текст/фон из семантической таблицы выше.

---

## 5. Иконки

- **Библиотека:** Lucide React (stroke, 2 px, скруглённые концы).
- **Стиль:** линейные, без заливки; в квадрате 32–40 px с мягким фоном `#E9EEFF` и иконкой `#2A48FF`.
- **Модули:** Home, ShoppingCart, Warehouse, ScanLine, FileBarChart.
- **Операции:** цвет иконки по типу (зелёный — приёмка, синий — отбор, янтарный — выдача, красный — утиль).

---

## 6. Тон и голос

- **Деловой, спокойный B2B** — как интерфейс ERP/WMS.
- Короткие глаголы: «Приёмка», «Отбор», «Выдача», «Утиль».
- Без сленга и излишней эмоциональности.
- Названия документов — как в системе: ЗН-006, ОП-001, ОТБ-001.
- Роли по-русски: Заведующий склада, Агроном, Администратор.

---

## 7. Чего избегать

- Тёмный фон слайдов (в приложении только светлая тема).
- Кислотные градиенты, glassmorphism, неон.
- Шрифты с засечками, Comic Sans, декоративные display-шрифты.
- Перегруженные слайды (>6 пунктов).
- Иконки filled/3D/emoji вместо Lucide stroke.
- Цвета вне палитры (особенно произвольный красный/зелёный).
- Скриншоты с browser chrome — в продукте есть `.browser-chrome`, но для презентации лучше чистые макеты.

---

## 8. Тени и эффекты

- Карточки login/modal: `0 8px 32px rgba(33,33,33,0.1)`.
- Модалки: backdrop `rgba(0,0,0,0.4–0.45)`.
- Hover карточек: `translateY(-2px)` + усиленная тень (лёгкий lift).
- Кнопки: `active:scale(0.99)` — едва заметное нажатие (ТСД).
